# Bank Management System

A Windows console application written in C++ for managing bank clients, users, transactions, and currencies.

## Features

- Add, list, search, update, and remove client records
- Deposit, withdraw, and transfer funds
- Review transaction history and account balances
- Manage user accounts and access permissions
- Maintain currencies and calculate conversions
- Store application data in local text files

## Build and run

1. Install Visual Studio 2022 with the **Desktop development with C++** workload and the MSVC v143 toolset.
2. Open the Visual Studio project file in the repository root.
3. Select the `x64` platform and a configuration, then build and run the project.
4. Run the application with the repository as its working directory so its text data files are found.

This is a Windows console project; it does not use a web server or database.
